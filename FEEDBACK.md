# FEEDBACK.md — Uniswap API issues

The API docs are quite extensive and the skills make it really easy to integrate. There is an endpoint missing for me that would give me the user’s wallet open positions. Today /lp/decrease and related LP calls expect you to already know the NFT token id plus token0/token1 (and for decrease, liquidityPercentageToDecrease), but there is no clean REST way to list all open v3 NFT positions for a wallet. In Sentinel we had to fall back to on-chain NonfungiblePositionManager RPC (balanceOf / tokenOfOwnerByIndex / positions) and then compute token amounts ourselves from liquidity + pool slot0 sqrt price, because the API also does not return human-readable amount0/amount1. A GET/POST /lp/positions?wallet=… (or similar) that returns open NFTs with pool, fee tier, ticks, and current token balances would make agent and portfolio UIs much simpler and keep Uniswap as the single source of truth instead of mixing API + raw RPC.
